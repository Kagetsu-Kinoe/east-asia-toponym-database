# 『三国史記』地理志　全地名のアイヌ語解釈

**坂東の雲／木上欠月**

古代朝鮮半島の地名は1145年に完成した『三国史記』の「地理志」（巻34-37）に記載されています。これには統一新羅時代の景徳王の時に改称された漢風地名（757年～）、景徳王以前、主に高句麗時代のもとの地名（～757年）、高麗時代の『三国史記』編纂当時の地名（1145年）の変遷の記録があります。

これら異なる三つの時代の地名はいずれもアイヌ語解釈可能で、基本的に治所周辺の同一地勢を指した言い換え表現となっています。

特筆すべきは、すべての地名において、例外なく当時の朝鮮半島の言語であるアイヌ語地名に極めて精密に漢字の音韻が充てられているということです。

---

## 仮説

### 一．東夷南蛮と朝鮮半島先住民の、言語的・生物学的グラデーション

中国の漢代の県名を見るに、中国の四夷の言語はおそらくはアイヌ語です。中原の圧迫を逃れた東夷南蛮の人々が朝鮮半島に移住し、アイヌ語地名を漢字で写し取りました。そもそも、東夷南蛮と朝鮮半島、日本の先住民は、言語を共有する以上、厳密な区別は不可能です。これらの地域の人々は生物学的にグラデーションを帯びているだけの血を分けた同系同族です。縄文人も弥生人も明確な線引きはできません。対になるデータは、[中国漢代県名のアイヌ語解釈](../../han-dynasty/data/README.md) です。

朝鮮半島と中国を往来した人々はアイヌ語と中国語の天才的なバイリンガルだったと考えられるため、アイヌ語の地名に限りなく精密に漢字の音韻が割り当てられました。それは、高句麗時代から高麗時代まで不変でした。

中国文明の中心は中原で、ルーツとなる殷や周はヒプシサーマル期以降に南下してきた北方遊牧民だと筆者は考えていますから、基本的に先住民である四夷とは別民族です。ですから、中原にとってアイヌ語は所詮蛮族の言語でしかありませんでした。しかし、東夷のその先、朝鮮半島はアイヌ語を使う民族の本場でした。だから、異民族の検閲を受けたであろう中国漢代の県名よりも表現がはるかに多彩で音韻のズレもほとんどありません。『三国史記』は当時のアイヌ語ネイティブ話者の手によって書かれた貴重な書物です。

### 二．バイリンガル話者による精密な漢字音韻仮借と、時代を超えた共時的な言い換え

古代朝鮮半島の地名表記に関わった人々は、アイヌ語地名を漢字に変換して記録に残すだけではなく、それらをアイヌ語ネイティブとして、あとから自らが読める必要性があったのではないでしょうか。しかし、時代が下るにつれ、中国の漢字の発音は変化していきます。同時に、過去に仮借漢字を充てられた地名もアイヌ語で読めなくなっていきます。最新の発音に合わせて、地名を変えていく必要性が生じるのは当然のことです。

アイヌ語は同一地名の言い換え表現が多彩ですから、いずれの時代も、その土地土地に生きていた人々によって、言い換え表現はすでにたくさん存在していました。その土地の呼名の一つを漢字に変換してすくい上げればよかっただけだとすれば、実は、高句麗、統一新羅、高麗の各時代の地名は、時代差がまったく存在しないのかもしれません。そう考えれば、すべての時代の地名が、軌を一にした同一地勢の言い換え表現になっていることもスムーズに理解できます。

景徳王の時に改称された漢風地名も、実はアイヌ語地名の仮借表記で、以前の地名を短縮したに過ぎないことが多いです。『三国史記』地理志の地名は、例外なくこの法則に則っていて、比定地の地勢をことごとく正確に表現しています。もし、地勢と解釈が一致しない場合、それは比定地の特定が間違っているか、あるいは音韻の拾い方、解釈が間違っているかのいずれかです。当時の地名に充てられた漢字音韻を丁寧に拾い、アイヌ語解釈するだけで、自動的に古代人の地勢解説が登場します。

## 記載の層——［A］［B］［C］

『三国史記』の地名は、おおよそ次の形式で記されます。

1. 「**［地名B］**は、もと**［地名A］**で、景徳王代に改名した。今の**［地名C］**である。」
2. 「**［地名B］**は、もと**［地名A］**で、景徳王代に改名した。今もこれに因っている。」
3. 「**［地名B］**は、もと**［地名A］**で、景徳王代に改名した。今は**［地名C］**に合併されている。」

| 記号 | 時代 | おおよその年代 | 音韻の主な根拠 |
| --- | --- | --- | --- |
| **［A］** | 景徳王以前（主に高句麗） | ～757年 | 上古音 |
| **［B］** | 景徳王代（統一新羅の漢風地名） | 757年～ | 随唐音 |
| **［C］** | 『三国史記』編纂時（高麗） | 1145年 | 随唐音 |

命名時期の不明瞭な［A］は上古音を、［B］［C］は随唐音を参考に解釈します。該当しない記載は、金富軾（井上秀雄訳注、平凡社）の本文に従います。

景徳王以前の地名は、紀元後、漢字音末尾の「ɡ」「ɣ」が脱落しつつある時期にあたることが多いです。末尾の響きは弱化し、ときに失われます。たとえば「兮」「牙」の類は、脱落の過程で音韻末尾が「エン」あるいは「ウン」へと弱化した例があります。

解釈の順は、『三国史記』の掲載順には従いません。日本と縁の深い朝鮮半島南東部から西方の海沿いに進み、さらに北上します。

## 解釈の前提

『三国史記』地理志地名のアイヌ語解釈の前提として。

アイヌ語の子音の「ル(r)」は漢字音には存在しないため、もっぱら「ュ(yu)」の音の漢字が充てられたと考えています。これは漢代の県名にもあてはまることです。ですから、「シル(sir)＝山」は「シュ(syu)」、「キル(kir)＝山脚」は「キュ(kyu)」という発音の漢字が充てられることになります。「レル(rer)＝山陰」の場合は「レュ(ryu)」、「ピル(pir)＝傷（のように切り刻まれたような地勢）」は「ピュ(pyu)」です。

「シル(sir)」や「キル(kir)」は実際に「シュ(syu)」や「キュ(kyu)」の発音に近かった可能性があります。北海道アイヌ語で「シル・アゥ(sir-aw)＝山の・角、枝分かれ」は「シラウ(siraw)」、「キル・アゥ(kir-aw)＝山脚の・角、枝分かれ」は「キラウ(kiraw)」と発音されますが、『三国史記』の漢字音を見ていると、「シュアゥ(syuaw)」、「キュアゥ(kyuaw)」となっています。北海道アイヌ語の方が、後世、開音音節言語の日本語の影響を受けているのではないでしょうか。

同様に「tu＝峰」は、北海道アイヌ語では「トゥ(tou)」と表記されることが多いですが、この「t」も「ティゥ(tiw)」の発音に近くなります。『三国史記』の漢字の音韻を見ると、「テュ(tu)」から「デュ(dyu)」「ヂュ(zyu)」の変化が読み取れます。

「テュ(tu)＝峰」と「チゥ(ciw)＝水流、水脈」の解釈がクロスして、両方に同じ漢字が使用されることもあります。このように、あえて複数の解釈が可能な漢字を充て、ダブルミーニングを意図しているかのような地名が頻繁に登場します。例えば、「城」は「テュ・エ・エン(tu-e-en)」or「チゥ・エ・エン(ciw-e-en)」と解釈でき、「峰が・そこで・突き出ている（ところ）」or「水流、水脈が・そこで・突き出ている（ところ）」となりますが、両方の特徴を持つ地勢を表現した例があります。また、「アク(ak)」は「弟（のように小さいもの）」と「矢を射る（ところ）」の意味がありますが、これもいずれの解釈も採用して「小さく鋭く尖った峰」の形容に使われることがほとんどです。

高句麗時代の地名に含まれる「忽」のほぼすべては、アイヌ語の「ムィ・アッ(muy-at)＝頂が・たくさんある」の意です。それが統一新羅で「城」の「テュ・エ・エン(tu-e-en)＝峰が・そこで・突き出ている（ところ）」に変換されたと考えています。城が築かれるのは、峰の上ですから地勢が一致するのは当然です。

これらの例のようにすべて、リエゾン、シラブルで解釈し、一文字の漢字を複数のアイヌ語の単語の連続で解釈します。

地名とは、正史のように為政者によってきれいに化粧されたものではありません。それだけに、古代その土地に生きた人々の生の声がそのまま保存されています。アイヌ語の発音に精密に漢字の音韻が充てられた『三国史記』地理志は、古代の名もなき庶民の声を現代の私達に届けてくれる貴重な書物です。

## 凡例

### 音韻

上古音／随唐音の配列は、次のとおりです。

**高本漢系統／王力系統／董同龢系統／周法高系統／李方桂系統／陳新雄系統**（陳新雄は随唐音のみ）

- 各項は「聲母」「半角スペース」「韻母」の順に置きます。
- 当該の説が存在しないものは `-` と記します。
- 同一地名に同じ音韻行が重なる場合は一つに整理します。ただし上古音と随唐音が両方ある漢字は、両方を残します。

参考：[漢字古今音資料庫](https://xiaoxue.iis.sinica.edu.tw/ccr/)

### アイヌ語

解釈はリエゾンとシラブルにより、一文字の漢字を複数のアイヌ語単語の連続として読みます。カタカナに付したローマ字は、知里真志保『地名アイヌ語小辞典』の表記に準じます。

| 約束 | 例 |
| --- | --- |
| し＝**si**、ち＝**ci**、つ＝**tu**、ふ＝**hu** | shi / chi / tsu / fu とはしません |
| 小さい仮名は語末子音 | キル＝**kir**、アム＝**am**、アク＝**ak** |
| テュ＝**tu** | tyu とはしません |
| 有声音と無声音を区別しません | 城＝テュ・エ・エン、またはデュ・エ・エン |

アイヌ語「ク」は「弓」ですが、朝鮮半島では「矢」の可能性があります。サハリンおよびシベリア・アムール流域のニヴフ（ギリヤーク）語でも「ク＝矢」です。

### データの欄

抽出データは、各地名について次の欄に分解しています。

| 欄 | 内容 |
| --- | --- |
| 州名 | 統一新羅の州 |
| 見出し | 本文の地名見出し |
| 現行地 | 「現／…」に記された比定地 |
| 統一新羅地名 | ［B］ |
| 景徳王以前地名 | ［A］ |
| 三国史記編纂時地名 | ［C］ |
| 音韻データ | 上古音・随唐音 |
| アイヌ語解釈 | カタカナ・ローマ字・日本語義 |

ローマ字ルビは、本文では漢字音の上に、データファイルでは 「ピル・アゥ・ウン・キル・ク(pir-aw-un-kir-ku)」のように、カタカナを中黒でつなぎ、ローマ字を末尾の括弧にハイフンでまとめて残します。
