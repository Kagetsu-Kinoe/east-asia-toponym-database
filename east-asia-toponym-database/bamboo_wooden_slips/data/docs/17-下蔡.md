## 関里

| 区画 | 下蔡 |
| 命名由来 | 所属：下蔡（直属・領域内）※簡121。被告の供述のなかで、真犯人の一人とされる人物の居住地として「下蔡関里人應女返」と記録されており、下蔡の管轄下にある里として確定。 |

| アイヌ語解釈 | アイヌ語：関（里）＝「ク・アゥ・ウン(ku-aw-un)」<br>＝「矢の（ように鋭い）・角、枝分かれ・にある（ところ）」<br>※アイヌ語「ク＝弓」。中国大陸、朝鮮半島では「ク＝矢」の可能性。サハリン、シベリアのニヴフ（ギリヤーク）語も「ク＝矢」。 |
