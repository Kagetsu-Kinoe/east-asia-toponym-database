# 古代中国木簡竹簡地名のアイヌ語解釈

**坂東の雲／木上欠月**

[『三国史記』地理志](../../samguk-sagi/data/README.md) の地名変遷で確立したアイヌ語解釈のルールは、[漢代の県名](../../han-dynasty/data/README.md)、[『山海経』の妖怪](../../sengaikyo/data/README.md)、[『書経』の「禹貢」](../../ukou/data/README.md) など、中国の地名でも一貫して通用しています。

しかし、朝鮮半島と中国地名の仮借表記には異なる傾向が見られます。『三国史記』地理志の地名は表現が多彩で豊かです。「アィ＝ハィ＝カジキマグロの顎」「アプ＝釣り針」「ラプ＝翼」などの表現が頻出します。一方の中国はまったく逆の傾向を見せます。単調なアイヌ語地名表現の繰り返しで、仮借表記の漢字は多彩でも、その実態は限られた少数のアイヌ語単語の組み合わせに過ぎません。「テュ＝峰」「シル＝山」「キル＝山脚」などが「アゥ＝枝分かれている」、「エン＝突き出ている」、そんなありきたりな表現で埋め尽くされています。特徴的なものをあえて抽出すれば、漢代の県名にみられた「道＝タク＝石」や「平＝ピ＝石（orピル＝傷のように切り刻まれたもの）」ぐらいなものでしょうか。

なぜ、このような現象が起こったのか。中原文化の良字二字強制の影響があることはもちろんですが、筆者が考えるに、最も大きな原因は地方から集められる情報に限界があったことです。漢代に紙が普及する以前、記録媒体は木簡、竹簡です。それを広大な中国の地方から中央まで運ぶ労力を鑑みれば、運べる量が限定的になるのは自明です。しかし、それでも紀元前の古文献には地方の情報が満載ですから、それらにはことごとく後世の人々の想像力、創作が多大に影響していると考えるのが妥当です。

例えば、四夷出身役人の言葉遊びともとれる『山海経』の妖怪達、そのあたりから尾ひれがついて儒家に神祖にされた五帝。史記に至り、物語がきれいに整えられ、それらは聖なる王の伝説として現在に至るまで綿々と語り継がれています。

史記の司馬遷は『山海経』の妖怪の出所がアイヌ語にあることが見抜けず、言及する価値がないと切り捨てています。司馬遷は中原の役人ですから、中原文化の漢字表記解釈では、『山海経』や漢代の県名の下に眠るアイヌ語地名にはまったくたどり着けなかったということになります。ここに両者を隔てる大きな文化の溝が厳然と存在しています。

筆者は生々しいアイヌ語地名を求めて中国の地方に眠る木簡、竹簡にたどり着きました。そこには中原の厚化粧を逃れた『三国史記』地理志と同じ表現豊かな地名が眠っているはずです。結果は、案の定、『居延漢簡』の解釈を始めて数時間後に、現地に立った者ならではの「カジキマグロの顎」や「釣り針」などの地勢表現が立て続けに現れました。これらは漢代の県名、『山海経』、「禹貢」ではまったく見られなかったものです。ここに『三国史記』地理志の親玉が登場したという訳です。

これらの仮借技術は、紀元前の中国大陸ですでに確立していて、それが朝鮮半島に渡って『三国史記』地理志となり、日本では八百万の神やおとぎ話に化けていきました。四夷が移動した先々で中国大陸で磨いた仮借技術を披露することで東アジアの歴史のベースが作られていくことになります。

木簡、竹簡の解釈方針は、アイヌ語地名の原型を残している可能性が高く、比定地の判明している地名が多いものから優先します。まずは『居延漢簡』。それから『懸泉漢簡』『里耶秦簡』『包山楚簡』と続く予定です。

前漢末〜後漢は、純正な上古音のシステムが崩壊し、隋唐の中古音へと向かう激しい過渡期にあります。特に、音節末尾の「-g」や「-ɣ」の脱落・弱化は、文字ごとにグラデーションを伴って進んでいました。そのため、『居延漢簡』などの音韻の地名解釈においては、「純正な上古音」をベースとしつつも、アイヌ語へと還元する過程で、当時の脱落・弱化を考慮して柔軟に解釈しています。これは『三国史記』地理志の地名解釈においても行っているものです。

## 解釈の前提

木簡・竹簡の解釈の前提として、漢代の県名でも採用したルールを適用します。

アイヌ語の子音の「ル(r)」は漢字音には存在しないため、もっぱら「ュ(yu)」の音の漢字が充てられたと考えています。ですから、「シル(sir)＝山」は「シュ(syu)」、「キル(kir)＝山脚」は「キュ(kyu)」という発音の漢字が充てられることになります。「レル(rer)＝山陰」の場合は「レュ(ryu)」、「ピル(pir)＝傷（のように切り刻まれたような地勢）」は「ピュ(pyu)」です。

「シル(sir)」や「キル(kir)」は実際に「シュ(syu)」や「キュ(kyu)」の発音に近かった可能性があります。北海道アイヌ語で「シル・アゥ(sir-aw)＝山の・角、枝分かれ」は「シラウ(siraw)」、「キル・アゥ(kir-aw)＝山脚の・角、枝分かれ」は「キラウ(kiraw)」と発音されますが、漢字音韻を見ると「シュアゥ(syuaw)」、「キュアゥ(kyuaw)」となっています。北海道アイヌ語の方が、後世、開音音節言語の日本語の影響を受けているのではないでしょうか。

同様に「tu＝峰」は、北海道アイヌ語では「トゥ(tou)」と表記されることが多いですが、この「t」も「ティゥ(tiw)」の発音に近くなります。漢字の音韻からは「テュ(tu)」から「デュ(dyu)」「ヂュ(zyu)」の変化が読み取れます。

「テュ(tu)＝峰」と「チゥ(ciw)＝水流、水脈」の解釈がクロスして、両方に同じ漢字が使用されることもあります。このように、あえて複数の解釈が可能な漢字を充て、ダブルミーニングを意図しているかのような地名が散見されます。また、「アク(ak)」は「弟（のように小さいもの）」と「矢を射る（ところ）」の意味がありますが、これもいずれの解釈も採用して「小さく鋭く尖った峰」の形容に使われることが多く見られます。

また、中国大陸では、「シ(si)」と「ヒ(hi)」が江戸弁のようにクロスする例が多数見られます。これは命名にあたった役人の発音が影響しているのかもしれません。

解釈はすべてリエゾン、シラブルにより、一文字の漢字を複数のアイヌ語の単語の連続として読みます。

## 凡例

### 音韻

上古音の配列は、次のとおりです。

**高本漢系統／王力系統／董同龢系統／周法高系統／李方桂系統**

- 各項は「聲母」「半角スペース」「韻母」の順に置きます。
- 当該の説が存在しないものは `-` と記します。

参考：[漢字古今音資料庫](https://xiaoxue.iis.sinica.edu.tw/ccr/)

### アイヌ語

解釈はリエゾンとシラブルにより、一文字の漢字を複数のアイヌ語単語の連続として読みます。カタカナに付したローマ字は、知里真志保『地名アイヌ語小辞典』の表記に準じます。

| 約束 | 例 |
| --- | --- |
| し＝**si**、ち＝**ci**、つ＝**tu**、ふ＝**hu** | shi / chi / tsu / fu とはしません |
| 小さい仮名は語末子音 | キル＝**kir**、アム＝**am**、アク＝**ak** |
| テュ＝**tu** | tyu とはしません |
| 有声音と無声音を区別しません | 城＝テュ・エ・エン、またはデュ・エ・エン |

アイヌ語「ク」は「弓」ですが、中国大陸および朝鮮半島では「矢」の可能性があります。サハリンおよびシベリア・アムール流域のニヴフ（ギリヤーク）語でも「ク＝矢」です。

### データの欄

抽出データは、各地名について次の欄に分解しています。

| 欄 | 内容 |
| --- | --- |
| 資料 | 居延漢簡・懸泉漢簡・里耶秦簡など、出土資料の名 |
| 分類 | 防衛組織・軍事要塞／のろし台（熢）／一般行政区画（郷・里）／シルクロード河西回廊全駅、主要行政・軍事拠点／遷陵県および周辺の県・郡 |
| 区画 | 東郷・西郷・南郷・別行政区画、置駅の一覧見出し、遷陵県（出土地・最前線軍事要塞）、周辺の県・郡。軍事地名では空 |
| 所属郡 | 懸泉漢簡の「漢代の所属郡」。居延漢簡・里耶秦簡では空 |
| 見出し | 本文の「■」に記された地名 |
| 比定地／地勢 | 「比定地／地勢」「比定地」「地勢（通説）」「地勢／位置関係」 |
| 遺跡番号 | 「遺跡番号／位置関係」または「遺跡」。郷の見出しに付された番号は、その郷の里が継承します |
| 命名由来 | 「命名由来（通説）」または「役割」。空のときは項目を出さない |
| 音韻データ | 上古音 |
| アイヌ語解釈 | カタカナ・ローマ字・日本語義 |

ローマ字ルビは、本文では漢字音の上に、データファイルでは 「キル・アク・テュ・アゥ・ウン(kir-ak-tu-aw-un)」のように、カタカナを中黒でつなぎ、ローマ字を末尾の括弧にハイフンでまとめて残します。本文にローマ字ルビがない見出しは、カタカナのみです。
