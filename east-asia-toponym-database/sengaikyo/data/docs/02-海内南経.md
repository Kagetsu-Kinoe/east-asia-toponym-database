## 甌（現／浙江省周辺）

| | |
| --- | --- |
| 篇名 | 海内南経 |
| 条 | 甌・閩 |
| 山海経訳 | 「甌（おう）は海の中に居る。閩（びん）は海の中にあり、その西北に山がある。一説には、閩中（びんちゅう）の山は海の中にあるという。」 |
| 現行地 | 浙江省周辺 |
| 音韻データ | 上古音：「甌」- -／ʔ u／0 ɔ／ʔ ûɡ／ʔ ew／· ug |
| アイヌ語解釈 | アイヌ語：甌＝「ウ・ク(u-ku)」<br>＝「互いに重なるような・矢（のように鋭い峰）」<br>※アイヌ語「ク＝弓」。中国大陸、朝鮮半島では「ク＝矢」の可能性。サハリン、シベリアのニヴフ（ギリヤーク）語も「ク＝矢」。 |
