# 『山海経』地名・妖怪のアイヌ語解釈

**坂東の雲／木上欠月**

『山海経』は戦国から漢代に成立した最古の地理書で、その荒唐無稽な内容から奇書扱いされています。奇々怪々な妖怪たちの様々な奇行が描かれ、司馬遷も語るに足らないと一蹴しています。

しかし、その実態は違います。『山海経』に登場する無数の妖怪とそれらを形容する内容は、その実、アイヌ語によくある同一地勢を表現した言い換え表現となっています。アイヌ語地名の仮借漢字を定型文や辻褄合わせの創作でつないでいるに過ぎません。

『山海経』の妖怪とアイヌ語の精密な音韻の一致を見ると、いずれの言語にも精通している作者の人物像が浮かび上がります。比定地の地勢をアイヌ語で表現しながら、故意に妖怪に仕立て上げたのでしょうか。そして、司馬遷を代表とする中央役人がそれをアイヌ語で読めなかったとするならば、この『山海経』の編纂意図はいったいなんだったのでしょう。

『山海経』と同じ構図は漢代の県名にもあてはまります。漢代の県名もアイヌ語解釈可能ですが、これも中央の上層部は理解できなかったのかもしれません。対になるデータは、[中国漢代県名のアイヌ語解釈](../../han-dynasty/data/README.md)、[『三国史記』地理志　全地名のアイヌ語解釈](../../samguk-sagi/data/README.md) です。

『山海経』と漢代の県名は、四夷のアイヌ語地名が暗号として封印された形になっている可能性が非常に高いと言えます。『山海経』の場合は妖怪、漢代の県名の場合は”良字二字”に巧みにカムフラージュされています。

山海経は、五蔵山経、海外四経、海内四経、大荒四経、海内経から構成されています。本稿では、比定地が判明しているものを優先し、海内四経と五蔵山経のうち西山経の山岳をアイヌ語解釈しています。掲載順は、日本に関係の深い「倭」（海内北経の特別編）、海内南経、海内西経、海内北経、海内東経、西山経です。

また、中国語とアイヌ語音韻の類似性による過剰適合の解釈の罠を避けるために、妖怪とその形容以外、方位や定型文等は原則として解釈しません。過剰適合については、[『禹貢』の付記](../../ukou/data/README.md) をご参照下さい。

## 解釈の前提

『山海経』の解釈の前提として、漢代の県名でも採用したルールを適用します。

アイヌ語の子音の「ル(r)」は漢字音には存在しないため、もっぱら「ュ(yu)」の音の漢字が充てられたと考えています。ですから、「シル(sir)＝山」は「シュ(syu)」、「キル(kir)＝山脚」は「キュ(kyu)」という発音の漢字が充てられることになります。「レル(rer)＝山陰」の場合は「レュ(ryu)」、「ピル(pir)＝傷（のように切り刻まれたような地勢）」は「ピュ(pyu)」です。

「シル(sir)」や「キル(kir)」は実際に「シュ(syu)」や「キュ(kyu)」の発音に近かった可能性があります。北海道アイヌ語で「シル・アゥ(sir-aw)＝山の・角、枝分かれ」は「シラウ(siraw)」、「キル・アゥ(kir-aw)＝山脚の・角、枝分かれ」は「キラウ(kiraw)」と発音されますが、漢字音韻を見ると「シュアゥ(syuaw)」、「キュアゥ(kyuaw)」となっています。北海道アイヌ語の方が、後世、開音音節言語の日本語の影響を受けているのではないでしょうか。

同様に「tu＝峰」は、北海道アイヌ語では「トゥ(tou)」と表記されることが多いですが、この「t」も「ティゥ(tiw)」の発音に近くなります。漢字の音韻からは「テュ(tu)」から「デュ(dyu)」「ヂュ(zyu)」の変化が読み取れます。

「テュ(tu)＝峰」と「チゥ(ciw)＝水流、水脈」の解釈がクロスして、両方に同じ漢字が使用されることもあります。このように、あえて複数の解釈が可能な漢字を充て、ダブルミーニングを意図しているかのような地名が散見されます。また、「アク(ak)」は「弟（のように小さいもの）」と「矢を射る（ところ）」の意味がありますが、これもいずれの解釈も採用して「小さく鋭く尖った峰」の形容に使われることが多く見られます。

また、中国大陸では、「シ(si)」と「ヒ(hi)」が江戸弁のようにクロスする例が多数見られます。これは命名にあたった役人の発音が影響しているのかもしれません。

## 凡例

### 音韻

上古音の配列は、次のとおりです。西山経の一部には随唐音もあります。

**高本漢系統／王力系統／董同龢系統／周法高系統／李方桂系統**

- 各項は「聲母」「半角スペース」「韻母」の順に置きます。
- 当該の説が存在しないものは `-` と記します。

参考：[漢字古今音資料庫](https://xiaoxue.iis.sinica.edu.tw/ccr/)

### アイヌ語

解釈はリエゾンとシラブルにより、一文字の漢字を複数のアイヌ語単語の連続として読みます。カタカナに付したローマ字は、知里真志保『地名アイヌ語小辞典』の表記に準じます。

| 約束 | 例 |
| --- | --- |
| し＝**si**、ち＝**ci**、つ＝**tu**、ふ＝**hu** | shi / chi / tsu / fu とはしません |
| 小さい仮名は語末子音 | キル＝**kir**、アム＝**am**、アク＝**ak** |
| テュ＝**tu** | tyu とはしません |
| 有声音と無声音を区別しません | 城＝テュ・エ・エン、またはデュ・エ・エン |

アイヌ語「ク」は「弓」ですが、中国大陸および朝鮮半島では「矢」の可能性があります。サハリンおよびシベリア・アムール流域のニヴフ（ギリヤーク）語でも「ク＝矢」です。

### データの欄

抽出データは、各地名について次の欄に分解しています。

| 欄 | 内容 |
| --- | --- |
| 篇名 | 海内四経・西山経など、本文の回に対応する篇 |
| 条 | 本文の「■■■」見出し |
| 見出し | 「◎アイヌ語：」に記された地名・妖怪名 |
| 山海経訳 | 「◇山海経訳」の訳文 |
| 現行地 | 「比定地：」に記された比定。空のときは項目を出さない |
| 距離補正 | 西山経の里程換算。空のときは項目を出さない |
| 音韻データ | 上古音・随唐音 |
| アイヌ語解釈 | カタカナ・ローマ字・日本語義 |

ローマ字ルビは、本文では漢字音の上に、データファイルでは 「ピル・アゥ・ウン・キル・ク(pir-aw-un-kir-ku)」のように、カタカナを中黒でつなぎ、ローマ字を末尾の括弧にハイフンでまとめて残します。
