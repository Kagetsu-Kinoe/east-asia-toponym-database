## 荊

| | |
| --- | --- |
| 州名 | 荊州 |
| 禹貢白文 | 「荊及衡陽惟荊州。江、漢朝宗于海，九江孔殷，沱、潛既道，雲土夢作乂。厥土惟塗泥，厥田惟下中，厥賦上下。厥貢羽、毛、齒、革、惟金三品，杶、幹、栝、柏，礪砥、砮、丹、惟箘簬、楛。三邦厎貢。厥名包匭菁茅。厥篚玄纁璣組。九江納錫大龜。浮于江、沱、潛、漢，逾于洛，至于南河。」 |
| 禹貢日本語訳 | 「荊山から衡山の南までが、荊州の地域である。長江と漢水は、まるで諸侯が天子に拝謁するように東の海へと流れ込んでおり、九本の川もすっかり整備されて正しく流れるようになった。長江の支流である沱水や潜水もすでに本来の川筋を通り、雲夢沢の広大な湿地も、干上がって農業や居住ができる土地になった。この土地の土質は、泥混じりの湿った粘土である。田の等級は九等中の第8等（下中）であるが、収穫量に応じた賦税の等級は、それよりも高く九等中の第3等（上下）に設定されている。貢納物としては、鳥の羽、獣の毛、象牙、皮革、三種の金属（金・銀・銅）、杶、榦、栝、柏といった弓の材料になる木材、そして砥石、矢尻にするための鋭い石、青色の顔料、さらに箘、簵、楛といった矢の柄になる優れた竹や木が納められた。これらについては、江漢の地にある三つの国がその名産品を選び抜いて定命の貢物とした。また、神事に用いる菁茅を箱に詰めて縛り、黒色や赤黄色の細帯や、穴の開いた美しい真珠を編んだ組紐を丸籠に入れて納めた。さらに九江の地方からは、占いに使う特大の亀が特別に献上された。これらの貢納物は、長江、沱水、潜水、漢水へと船で浮かべ、陸路で洛水へと担ぎ越え、さらに南河に出て、帝都へと運ばれた。」 |
| 比定地 | 荊山。湖北省襄陽市（南漳県）にある山。荊州の北の起点。 |
| 音韻データ | 上古音：「荊」k i̯ĕŋ／k ǐeŋ／k jĕŋ／k ieŋ／k jing |
| アイヌ語解釈 | アイヌ語：「荊」<br>＝「キル・エ・エン(kir-e-en)」<br>＝「山脚が・そこで・突き出ている（ところ）」 |
