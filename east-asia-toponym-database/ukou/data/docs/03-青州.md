## 青（州）

| 州名 | 青州 |
| 禹貢白文 | 「海岱惟青州，嵎夷既略，濰淄其道。厥土白墳，海濱廣斥。厥田惟上下，厥賦中上。厥貢鹽絺，海物惟錯。岱畎絲、枲、鈆、松、怪石。萊夷作牧。厥篚檿絲。浮于汶，達于濟。」 |
| 禹貢日本語訳 | 「東の海と西の泰山のあいだの地域が青州である。東の最果ての地はすでに治まり、濰水と淄水の治水が完了して正しく流れるようになった。その土地の土質は白く、ふっくらと肥えているが、海沿いは広大な塩分を含んだ湿地である。田の等級は「上下」（上から3番目）であるが、税の等級は「中上」（上から4番目）である。貢物は塩や葛布であり、そのほか様々な海の産物が交じり合っている。さらに泰山の谷間からは、生糸、からむし、鉛、松の木、珍しい形の鑑賞石が産出される。萊夷の地は、放牧に適した地とされた。竹かごに入れて献上する上質な品は、山桑の繭から紡いだ頑丈な生糸である。これらの貢物は、汶水・遂水に船を浮かべて運び、済水へと乗り入れて中央へと運ばれる。」 |
