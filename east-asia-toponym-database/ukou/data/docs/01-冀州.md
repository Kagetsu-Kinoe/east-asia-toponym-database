## 冀（州）

| | |
| --- | --- |
| 州名 | 冀州 |
| 禹貢白文 | 「禹敷土、随山刊木、奠高山大川。冀州既載壺口、治梁及岐。既修太原、至于岳陽。覃懐厎績、至于衡漳。厥土惟白壌、厥賦惟上上錯、厥田惟中中。恒衛既従、大陸既作。島夷皮服、夾右碣石、入于河。」 |
| 禹貢日本語訳 | 「禹は天下の土地を整理し、山々に登って木を切り払い、高い山や大きな川の境界を定められた。<br>冀州では、まず壺口の山から着手し、梁山や岐山の周辺を治めた。太原の盆地を整備し、太岳山の南側まで開拓を広げた。覃懐の地で治水の見事な成果が上がり、さらに衡水や漳水の流域へと及んだ。<br>その土地の土壌は「白壌（白い柔らかい土）」である。田の等級は「中の中」であるが、賦の等級は「上の上」であり、例外的にこれより上下することもある。<br>恒水や衛水は定められた川筋を流れるようになり、大陸澤の湿地帯も耕作ができるようになった<br>東北の島々に住む先住民は、毛皮の衣服を献上するようになった。右手に碣石山を見ながら海沿いを進み、黄河へと入って都へ運ぶ。」 |
| 比定地 | 中国の北部一帯。現在の山西省全域、河北省の大部分、河南省の黄河以北、および内モンゴル自治区・遼寧省の一部にまたがる広大な地域。 |
