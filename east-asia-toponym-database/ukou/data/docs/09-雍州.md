## 雍州

| | |
| --- | --- |
| 州名 | 雍州 |
| 禹貢白文 | 「黒水、西河惟雍州。弱水既西，涇屬渭汭，漆、沮既從，灃水攸同。荊、岐既旅，終南、惇物，至於鳥鼠。原隰厎績，至於豬野。三危既宅，三苗丕敘。厥土惟黃壤，厥田惟上上，厥賦惟中下。厥貢惟球、琳、琅玕。浮于積石，至於龍門、西河，會于渭汭。織皮崑崙、析支、渠搜，西戎即敘。」 |
| 禹貢日本語訳 | 「黒水から西河までが、雍州である。弱水はすでに西へ流れ、涇水は渭水の湾曲部に合流し、漆水と沮水も渭水に従い、灃水もまた一か所に集まった。荊山と岐山はすでに神々を祀る祭祀が行われ、終南山や惇物山から鳥鼠同穴山にいたるまでの山々もすべて整備された。高台の原野も低層の湿地も成果が上がり、猪野の沼沢地にいたるまで水が引いて土地が安定した。三危山のふもとには人々が定住できるようになり、三苗の部族も大いに秩序づけられた。その土壌は黄色く肥えた黄壌である。その田はもっとも上等な「上上」であり、その賦は「中下」である。その貢納物は、美しい玉である球、琳、琅玕である。これらを運ぶ船は積石山のふもとから黄河に浮かび、龍門や西河を通り、渭水の湾曲部で合流する。毛織物や皮衣を貢ぐ崑崙、析支、渠搜といった西方の異民族たちも、みな服従し従うようになった。」 |
| 比定地 | 現在の陝西省、甘粛省、寧夏回族自治区、青海省、内モンゴル自治区の一部にまたがる、中国北西部の広大な地域（黄土高原や関中盆地一帯） |
| 音韻データ | 上古音：「雍」ʔ i̯uŋ／0 ǐwɔŋ／- -／ʔ jewŋ／- -<br>上古音：「州」tɕ ／ȶ ǐ u／ȶ jŏ ɡ／t jəw／t jəgw |
| アイヌ語解釈 | アイヌ語：「雍州」<br>＝「イ・アゥ・ウン・テュ・アク(i-aw-un-tu-ak)」<br>＝「その・角、枝分かれ・にある・峰の・弟」 |

## 析支

| | |
| --- | --- |
| 州名 | 雍州 |
| 禹貢白文 | 「黒水、西河惟雍州。弱水既西，涇屬渭汭，漆、沮既從，灃水攸同。荊、岐既旅，終南、惇物，至於鳥鼠。原隰厎績，至於豬野。三危既宅，三苗丕敘。厥土惟黃壤，厥田惟上上，厥賦惟中下。厥貢惟球、琳、琅玕。浮于積石，至於龍門、西河，會于渭汭。織皮崑崙、析支、渠搜，西戎即敘。」 |
| 禹貢日本語訳 | 「黒水から西河までが、雍州である。弱水はすでに西へ流れ、涇水は渭水の湾曲部に合流し、漆水と沮水も渭水に従い、灃水もまた一か所に集まった。荊山と岐山はすでに神々を祀る祭祀が行われ、終南山や惇物山から鳥鼠同穴山にいたるまでの山々もすべて整備された。高台の原野も低層の湿地も成果が上がり、猪野の沼沢地にいたるまで水が引いて土地が安定した。三危山のふもとには人々が定住できるようになり、三苗の部族も大いに秩序づけられた。その土壌は黄色く肥えた黄壌である。その田はもっとも上等な「上上」であり、その賦は「中下」である。その貢納物は、美しい玉である球、琳、琅玕である。これらを運ぶ船は積石山のふもとから黄河に浮かび、龍門や西河を通り、渭水の湾曲部で合流する。毛織物や皮衣を貢ぐ崑崙、析支、渠搜といった西方の異民族たちも、みな服従し従うようになった。」 |
| 比定地 | 青海省の黄河上流の湾曲部。現在の果洛・海南チベット族自治州一帯。 |
| 音韻データ | 上古音：「析」s iek／s iek／s iek／s ek／s ik<br>上古音：「支」ȶ i̯ĕɡ／ȶ ǐe／c jeɡ／t jieɣ／k rjig |
| アイヌ語解釈 | アイヌ語：「析支」<br>＝「シル・アク・テュ・アク(sir-ak-tu-ak)」<br>＝「山の・弟（のように小さいもの）・峰の・弟」 |
