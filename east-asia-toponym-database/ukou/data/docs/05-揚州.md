## 揚（州）

| | |
| --- | --- |
| 州名 | 揚州 |
| 禹貢白文 | 「淮海惟揚州。彭蠡既豬，陽鳥攸居。三江既入，震澤厎定。篠、簜既敷，厥草惟夭，厥木惟喬。厥土惟塗泥。厥田唯下下，厥賦下上，上錯。厥貢惟金三品，瑤、琨、篠、簜、齒、革、羽毛惟木。鳥夷卉服。厥篚織貝，厥包橘柚，錫貢。沿于江、海，達于淮、泗。」 |
| 禹貢日本語訳 | 「淮河から海にいたる地域が、揚州である。彭蠡の水は一箇所に集まり、渡り鳥がそこに落ち着いて住めるようになった。三江が海へと流れ込み、震澤の水害も収まって安定した。篠や簜が一面に茂り、その草は非常に青々と生い茂り、木々は高くまっすぐに伸びた。この地の土は泥である。田畑の等級は「下下」であるが、税の等級は「下上」であり、年によってはさらに上の等級が混じることもある。その貢物は、三品の金属、瑶や琨、篠・簜、象牙、皮革、羽毛、獣の毛、そして木材である。ここに住む鳥夷は、草で編んだ衣服を着ている。竹籠に詰めた貝紫の織物、および包みにした橘や柚は、命じられたときにだけ献上する。これらを都に運ぶ際は、長江や海を沿うように下り、淮河や泗水に到達して都へと向かう。」 |
| 比定地 | 淮河より南、長江の下流域から、南の海岸線に至るまでの広大な江南・華南地域。 |
| 音韻データ | 上古音：「揚」d i̯aŋ／ʎ ǐaŋ／d jaŋ／r iaŋ／r ang |
| アイヌ語解釈 | アイヌ語：「揚（州）」<br>＝「テュ・アゥ・ウン(tu-aw-un)」<br>＝「峰の・角、枝分かれ・にある（ところ）」 |
