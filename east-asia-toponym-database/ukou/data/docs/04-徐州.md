## 徐州

| | |
| --- | --- |
| 州名 | 徐州 |
| 禹貢白文 | 「海岱及淮惟徐州。淮、沂其乂，蒙、羽其藝。大野既豬，東原厎平。厥土赤埴墳，草木漸包。厥田惟上中，厥賦惟下上。厥貢惟土五色，羽畎夏狄，嶧陽孤桐，泗濱浮磬，淮夷蠙珠及魚。厥篚玄纖縞。浮于淮、泗，達于河。」 |
| 禹貢日本語訳 | 「東の海、北の泰山、そして南の淮水に囲まれた地域が徐州である。淮水と沂水の流域はすでに治まり、蒙山と羽山の周辺は耕作ができるようになった。大野澤の水はせき止められて池（湖）となり、東原の地はよく平らになった。その土地の土質は赤く、粘り気があってふっくらと肥えており、草木は成長して次第に生い茂っている。田の等級は「上中」（上から2番目）と優れているが、税の等級は「中中」（上から5番目）である。貢物は五色の粘土、羽山の谷間から採れるキジの羽、嶧山の南側から採れる特産のキリの木、泗水のほとりから採れる浮磬（石磬の材料となる石）、そして淮水付近に住む先住民族（淮夷）が献上する真珠と魚である。竹かごに入れて献上する上質な品は、黒い薄絹ときめの細かい白絹である。これらの貢物は、淮水や泗水に船を浮かべて運び、黄河へと乗り入れて中央へと運ばれる。」 |
| 比定地 | 主に現在の山東省南部と江蘇省・安徽省の北部（淮河流域の北側）にまたがる平野部。北は泰山、南は淮河（わいが）に挟まれた地域。 |
