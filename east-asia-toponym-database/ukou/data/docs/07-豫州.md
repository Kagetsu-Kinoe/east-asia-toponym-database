## 豫（州）

| | |
| --- | --- |
| 州名 | 豫州 |
| 禹貢白文 | 「荊、河惟豫州。伊洛瀍澗、既入于河、滎波既豬。導菏澤、被孟豬。厥土惟壤、下土墳壚。厥田惟中上、厥賦錯上中。厥貢漆、枲、絺、紵。厥篚纖纊、錫貢磬錯。浮于洛、達于河。」 |
| 禹貢日本語訳 | 「荊山から黄河にいたる地域が豫州である。伊水・洛水・瀍水・澗水は、すべて黄河へと流れ込むようになった。滎波の水も堰き止められ、貯水池となった。菏澤の水を導き、その水は孟豬の沼沢地へと流れ込ませた。この地域の土質は柔らかな肥土であり、低地は盛り上がった黒く硬い粘土である。田の等級は「中上」（4等）である。税金の等級は「上中」（2等）であり、時に3等が混じる。貢物は、漆、麻、葛の細布、からむし織りの布である。籠に入れて献上する上等な品は、細い絹織物と、引き綿である。また、必要に応じて磬を作るための砥石を貢いだ。水路による輸送は、洛水に舟を浮かべ、そこから黄河へと達する。」 |
| 比定地 | 豫州は、中原とも呼ばれ、現在の河南省中心に安徽省・山東省・河北省の一部にまたがる広大な平原地帯。 |
| 音韻データ | 上古音：「豫」d io／ʎ ǐa／d jaɡ／r iaɣ／r agh |
| アイヌ語解釈 | アイヌ語：「豫（州）」<br>＝「テュ・アク(tu-ak)」<br>＝「峰の・弟（のように小さいもの）」 |
