## 兗（州）

| | |
| --- | --- |
| 州名 | 兗州 |
| 禹貢白文 | 「濟河惟兗州，九河既道，雷夏既澤，灉沮會同。桑土既蠶，是降丘宅土。厥土黑墳，厥草惟繇，厥木惟條。厥田惟中下，厥賦貞作，十有三載乃同。厥貢漆絲，厥篚織文。浮于濟漯，達于河。」 |
| 禹貢日本語訳 | 「済水と黄河に挟まれた地域が兗州である。氾濫していた黄河の下流の九本の河はスムーズに導かれ、雷夏の地は水が引いて正しい湖沢となった。灉水と沮水も合流して正しく流れるようになった。桑の育つ土地になったので蚕が飼えるようになり、人々は洪水から避難していた丘から下りて平地に住み着くようになった。その土壌は黒く肥えて柔らかく、草は生い茂り、木はまっすぐに伸びて高くなった。田の等級は中下（第6等）であり、税の額は正しく定められたが、治水工事が始まってから13年経ってようやく他の州と同じように安定して徴収できるようになった。その貢物は漆と絹糸であり、竹かごに詰めて納めるものは模様を織り込んだ織物である。貢物を運ぶ船は済水や漯水に浮かべて進み、黄河へと達する。」 |
| 比定地 | 現在の山東省の西部・北部、河南省の東部、および河北省の南部にまたがる地域。西は黄河、東は済水（かつて存在した大河）に挟まれた平野部。 |
| 音韻データ | 上古音：「兗」d i̯wan／ʎ ǐwan／- -／r iwan／- - |
| アイヌ語解釈 | アイヌ語：「兗（州）」<br>＝「リ・アゥ・ウン(ri-aw-un)」<br>＝「高い・角、枝分かれ・にある（ところ）」 |
