# 『尚書』禹貢地名のアイヌ語解釈

**坂東の雲／木上欠月**

『尚書』の一篇「禹貢」は、九州ごとの山河、貢物を記した中国最古の体系的な地理の記録です。禹が実在したとすれば、およそ紀元前二千年、「禹貢」の編纂はそれから千数百年後の紀元前三世紀頃です。

夏王朝の創始者である禹の治水の功業をまとめたものと伝えられていますが、これらの中に比定地がはっきりとしている地名が含まれていますので、周辺地勢との整合性を確認しながらアイヌ語解釈していきます。

別項のとおり[漢代の県名](../../han-dynasty/data/README.md)はすべてアイヌ語解釈可能です。それは中原が蛮族扱いした四夷こそが先住民で、漢字を用いた殷の方が侵略者であったことを示しています。殷はヒプシサーマル期以降に南下してきた北方系遊牧民で、夏王朝を征服、放伐して中国先住民の真ん中に盤踞しました。四夷、中華思想はそこから生まれています。

漢代の県名の解釈の虎の巻となったものは、朝鮮半島の[『三国史記』地理志](../../samguk-sagi/data/README.md)です。殷の時代からすでに千年以上、中国大陸において、仮借のルールははるか昔に確立されていて、それが朝鮮半島に渡って『三国史記』に書き写されたと考えれば、両者の法則の共通性がはじめて理解できることになります。

本項は『三国史記』地理志で確立させた解釈ルールを、漢代の県名同様、「禹貢」に登場する地名に当てはめてアイヌ語解釈したものです。

---

## 解釈の前提

禹貢の解釈の前提として、漢代の県名でも採用したルールを適用します。

アイヌ語の子音の「ル(r)」は漢字音には存在しないため、もっぱら「ュ(yu)」の音の漢字が充てられたと考えています。ですから、「シル(sir)＝山」は「シュ(syu)」、「キル(kir)＝山脚」は「キュ(kyu)」という発音の漢字が充てられることになります。「レル(rer)＝山陰」の場合は「レュ(ryu)」、「ピル(pir)＝傷（のように切り刻まれたような地勢）」は「ピュ(pyu)」です。

「シル(sir)」や「キル(kir)」は実際に「シュ(syu)」や「キュ(kyu)」の発音に近かった可能性があります。北海道アイヌ語で「シル・アゥ(sir-aw)＝山の・角、枝分かれ」は「シラウ(siraw)」、「キル・アゥ(kir-aw)＝山脚の・角、枝分かれ」は「キラウ(kiraw)」と発音されますが、漢字音韻を見ると「シュアゥ(syuaw)」、「キュアゥ(kyuaw)」となっています。北海道アイヌ語の方が、後世、開音音節言語の日本語の影響を受けているのではないでしょうか。

同様に「tu＝峰」は、北海道アイヌ語では「トゥ(tou)」と表記されることが多いですが、この「t」も「ティゥ(tiw)」の発音に近くなります。漢字の音韻からは「テュ(tu)」から「デュ(dyu)」「ヂュ(zyu)」の変化が読み取れます。

「テュ(tu)＝峰」と「チゥ(ciw)＝水流、水脈」の解釈がクロスして、両方に同じ漢字が使用されることもあります。このように、あえて複数の解釈が可能な漢字を充て、ダブルミーニングを意図しているかのような地名が散見されます。また、「アク(ak)」は「弟（のように小さいもの）」と「矢を射る（ところ）」の意味がありますが、これもいずれの解釈も採用して「小さく鋭く尖った峰」の形容に使われることが多く見られます。

また、中国大陸では、前述のように「シ(si)」と「ヒ(hi)」がクロスします。

解釈はすべてリエゾン、シラブルにより、一文字の漢字を複数のアイヌ語の単語の連続として読みます。

## 【付記】 『禹貢』全文アイヌ語解釈における過剰適合について。

筆者は『禹貢』の解釈過程で、全文すべてのアイヌ語解釈も試みましたが、驚くことにそれも無理なく可能でした。一見、アイヌ語地名に恣意的に漢字を充てて並べ、同時に禹の功績として読めるように、意図して仕立て上げられたと捉えることもできます。

これはなんということかと驚きましたが、解釈の妥当性を疑い、『漢書』や『山海経』など、他の文献も調べてみました。結果は似たようなものでした。

なぜ、こういう現象が起こるのか。筆者の考えは以下です。  
四夷の言語がもしアイヌ語であった場合、漢代の県名解釈の冒頭で述べたように、漢字の一部にはアイヌ語が取り込まれている可能性があります。であれば、別民族言語のアイヌ語と中国語ですが、その起源が重なる言語とも言え、似通った音韻を持っていたとしても何ら不思議はありません。日本の東北弁がアイヌ語訛りの可能性があるのと同じことです。

『禹貢』の全文解釈の具体例を下部にあげてみます。  
典型的なアイヌ語の景観表現として解釈できているように見えますが、これは実際の地勢という「基準点」が存在しないため、システムの自由度の高さによって「どのような景色も捏造できてしまう罠（過剰適合）」だと考えるのが妥当です。一部、正当な解釈が含まれる可能性も捨てきれませんが、それを厳密に検証する術が手元にありません。

上古音の音声設計そのものに「四夷のアイヌ語訛り（基層言語）」の響きが含まれていると仮定した場合、地名以外の普通の文章であってもアイヌ語の地勢描写が自ずと立ち上がってしまうのは、よくある空耳現象に同じです。例えば、上古音の音韻末尾には頻繁に「g」「ɣ」が登場しますが、これらの音韻は、アイヌ語によくある「k」の子音を表現したものかもしれません。こういった要素が、アイヌ語然とした文章を成立させてしまうことになるのです。

そして、この「g」「ɣ」「d」「r」などの末尾の音韻は、紀元後の中古音に向けて徐々に脱落、または変化していきます。筆者は、これがアイヌ語文化が消滅したタイミングだと考えています。『禹貢』はこれらの音韻が脱落する前に編纂されたものなので、全文アイヌ語で読めてしまった訳です。つまり、単に構造的な偶然に過ぎませんでした。

結論。いかに音韻が一致していようとも、『三国史記』地理志や漢代の県名など、比定地が明確で、地勢との関係を比較検証できる作業以外は、行うべきではないと判断します。あり得るとすれば、地勢以外の検証方法が設定できる場合だけです。  
後の研究者が同じ罠に嵌らないよう、この文章解釈の手法に問題があることをここに明記し、全文解釈の公開も差し控えさせていただくことにします。あしからず、ご了承ください。

## 凡例

### 音韻

上古音の配列は、次のとおりです。

**高本漢系統／王力系統／董同龢系統／周法高系統／李方桂系統**

- 各項は「聲母」「半角スペース」「韻母」の順に置きます。
- 当該の説が存在しないものは `-` と記します。

参考：[漢字古今音資料庫](https://xiaoxue.iis.sinica.edu.tw/ccr/)

### アイヌ語

解釈はリエゾンとシラブルにより、一文字の漢字を複数のアイヌ語単語の連続として読みます。カタカナに付したローマ字は、知里真志保『地名アイヌ語小辞典』の表記に準じます。

| 約束 | 例 |
| --- | --- |
| し＝**si**、ち＝**ci**、つ＝**tu**、ふ＝**hu** | shi / chi / tsu / fu とはしません |
| 小さい仮名は語末子音 | キル＝**kir**、アム＝**am**、アク＝**ak** |
| テュ＝**tu** | tyu とはしません |
| 有声音と無声音を区別しません | 城＝テュ・エ・エン、またはデュ・エ・エン |

アイヌ語「ク」は「弓」ですが、中国大陸および朝鮮半島では「矢」の可能性があります。サハリンおよびシベリア・アムール流域のニヴフ（ギリヤーク）語でも「ク＝矢」です。

### データの欄

抽出データは、各地名について次の欄に分解しています。

| 欄 | 内容 |
| --- | --- |
| 州名 | 禹貢の九州 |
| 見出し | 「◎アイヌ語：」に記された地名 |
| 禹貢白文 | 当該の州の白文 |
| 禹貢日本語訳 | 当該の州の日本語訳 |
| 比定地 | 「・比定地：」に記された比定。本文に記載がないものは空欄 |
| 音韻データ | 上古音 |
| アイヌ語解釈 | カタカナ・ローマ字・日本語義 |
| 出典 | 本文 HTML |

ローマ字ルビは、本文では漢字音の上に、データファイルでは 「キル・アゥ・ウン(kir-aw-un)」のように、カタカナを中黒でつなぎ、ローマ字を末尾の括弧にハイフンでまとめて残します。
